## 🐧 Linux Lab

This repository contains experiments and notes from Linux system programming and command line practice.

### 📘 Books used

- *The Linux Command Line, 3rd Edition* — William E. Shotts Jr.
- *The Linux Programming Interface* — Michael Kerrisk

---

### 🧪 Topics covered

#### Command line basics
- Filesystem navigation
- Pipes and redirection
- Process management
- Permissions and users

#### System programming
- System calls
- File descriptors
- Process creation (fork/exec)
- Signals
- Memory management basics

---

### ⚙️ Goals

- Understand Linux internals, not just commands
- Become comfortable with terminal-based workflows
- Learn how programs actually interact with the kernel
- Build intuition for debugging production-like issues

---

### 🧠 Notes

These notes are practical and experiment-driven, not theoretical summaries.
Expect command outputs, small tests, and behavior observations.
